# Análisis de Algoritmos

Repositorio para el curso de Análisis de Algoritmos (ITM). Aquí se recopilan ejercicios de clase, laboratorios y benchmarks realizados durante el semestre.

## Estructura del repositorio

```
AlgoritmosItm/
├── ejercicios-clase/   # Ejercicios resueltos durante las sesiones de clase
├── laboratorios/       # Laboratorios y talleres entregables
└── benchmarks/         # Mediciones de rendimiento y comparación de algoritmos
```

- **ejercicios-clase/**: código y notas de los ejercicios trabajados en clase.
- **laboratorios/**: soluciones a los laboratorios del curso, organizadas por número o tema.
- **benchmarks/**: scripts y resultados de pruebas de rendimiento (tiempos de ejecución, complejidad empírica, comparaciones entre algoritmos).

## Cómo usar este repositorio

Cada carpeta contendrá subcarpetas por tema o número de actividad, con su propio código fuente e instrucciones cuando sea necesario.
